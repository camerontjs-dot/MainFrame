# Live State Index

Information that changes, expires, or needs repeated updates.

Example domains (local only — not published):

- Operational dashboards and status boards
- Active research watchlists
- Time-bounded experiment notes

## Rule

Do not let dashboards become archives. Promote durable insights to `10_knowledge/`.

## Live databases (local)

Live SQLite files and telemetry stay gitignored. Query tools, when installed, use separate live indexes from durable MindGraph knowledge/project databases.
